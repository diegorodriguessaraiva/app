# 📚 Minha Agenda Escolar

Aplicativo web para administrar sua agenda de **deveres de casa**, **provas**, **trabalhos** e **datas importantes**.

## Como usar

Basta abrir o arquivo `index.html` em qualquer navegador — não precisa instalar nada, nem servidor, nem internet.

Você também pode publicá-lo gratuitamente com o **GitHub Pages** (Settings → Pages → branch principal) para acessar do celular.

## Funcionalidades

- ➕ **Adicionar itens** com título, tipo, matéria, data, hora e anotações
- 🏷️ **Tipos**: dever de casa, prova, trabalho, data importante e outros
- 📅 **Visualizações**: Próximos, Hoje, Esta semana, Atrasados, Concluídos e Todos
- 🔍 **Busca e filtros** por texto, tipo e matéria
- ⚠️ **Alertas visuais**: itens atrasados, para hoje, amanhã e próximos dias
- 📊 **Painel de resumo**: atrasados, para hoje, próximos 7 dias e provas por vir
- ✅ Marcar como concluído, editar e excluir
- 💾 **Salvamento automático** no navegador (localStorage)
- ⬇⬆ **Exportar/importar backup** em JSON
- 🌙 Tema claro/escuro automático conforme o sistema
- 📱 Layout responsivo (funciona bem no celular)

## Observações

Os dados ficam salvos no navegador em que você usa o app. Para trocar de dispositivo ou navegador, use **Exportar** em um e **Importar** no outro.
